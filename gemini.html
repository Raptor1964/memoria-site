Memoria è il password manager e cassaforte personale progettato con un'architettura Zero-Knowledge. Nessun server di terze parti, cifratura locale di livello militare e sincronizzazione diretta sul tuo Google Drive.

Scarica su Google Play
🛡️

Cifratura Locale Avanzata

I tuoi dati sono protetti da algoritmi di crittografia AES-256 GCM e derivation key via Argon2id / PBKDF2. Il database locale SQLite sfrutta SQLCipher per la cifratura completa a riposo.

🔐

Protezione Biometrica Hardware

Integrazione nativa con Android Keystore (Class 3 Strong Biometrics). Le tue chiavi sono protette nel chip di sicurezza del dispositivo e invalidate automaticamente se il set di impronte viene modificato.

☁️

Backup Privato Google Drive

Sincronizza i tuoi file e backup cifrati direttamente sul tuo spazio personale Google Drive. I tuoi dati non transitano mai da server proprietari o intermediari.

🔑

Generatore di Password

Crea al volo credenziali complesse e uniche, personalizzabili per lunghezza e set di caratteri per proteggere ogni tuo account da attacchi brute-force.

📁

Organizzazione Intelligente

Gestisci password, note riservate, carte di credito e documenti personali dividendo ogni elemento in categorie e tag facili da ricercare.

🚫

Zero Tracciamento

Nessuna profilazione utente, nessun tracciamento pubblicitario e zero telemetria invasiva. L'app lavora in locale per garantire la massima riservatezza.

Architettura di Sicurezza

Costruita con tecnologie moderne per garantire reattività, sicurezza e compatibilità nativa con le più recenti API Android.
