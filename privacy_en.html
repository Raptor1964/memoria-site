Privacy Policy

Last updated: September 16, 2026

This Privacy Policy describes how personal data is handled when using the mobile application Memoria: Password Manager (hereinafter referred to as the "Application"), developed by Giancarlo De Rosa.

1. General Principles and Data Collection

The Application is designed based on the principle of data minimization and local security. By default, no personal data is transmitted to external servers.

  • Vault Data (Accounts & Passwords): All data entered by the user (usernames, passwords, notes) is stored exclusively locally on your device. The Developer has zero access to this data.
  • Email Address (Optional): Providing an email address is optional and disabled by default. It is requested solely if the user chooses to enable the optional Assisted Recovery feature.
  • Google Account (Optional): Required only if the user decides to enable the personal backup feature via Google Drive.

2. Use of Google Drive (OAuth Scope)

For the optional backup feature, the Application requests access to the Google Drive API using the restricted scope:
https://www.googleapis.com/auth/drive.file

What this means: The Application can only view, create, and manage the specific files and folders that it creates. It has no access whatsoever to your other personal files or documents stored on Google Drive.

3. Optional Account Recovery Service

By default, if you lose your Master Password, the local database is unrecoverable. If you choose to enable the optional recovery feature:

  • Your password is securely stored inside your device's protected system (Android Keystore / SecureStorage).
  • In the event of a recovery request, your credentials will be sent to the email address specified by you.
  • It is the user's responsibility to change the Master Password immediately after recovery to restore full security to the local database.

4. Retention, Security, and Encryption

  • Encryption Standards: Vault data is protected locally using AES-256-GCM encryption. Key derivation is handled via the industry-standard Argon2id algorithm.
  • Zero Tracking: The Application uses no analytics tools, displays no advertisements, and does not track user behavior.
  • No Third-Party Sharing: No personal or technical data is sold, rented, or shared with third parties for commercial purposes.

5. Terms of Use

The Application may be used for personal or business purposes in accordance with this privacy policy and the terms provided by the app store: Google Play Terms of Service.

6. Disclaimer of Warranties

The Developer provides no express or implied warranties and is not liable for any data loss, or direct/indirect damages arising from the use of the Application or the loss of access credentials by the user.
